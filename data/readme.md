# 📚 Dataset

ExamGuard AI uses public datasets for initial experimentation and model development.

## Behavior Detection

We use the **CCTV Exam Monitor Dataset** as one of the initial datasets for training and evaluating examination-room behavior detection.

### Dataset Source
### images 
[Kaggle – CCTV Exam Monitor Dataset](https://www.kaggle.com/datasets/cctvdataset/cctv-exam-monitor-dataset?resource=download)
[ExamCheating MultiV-based Dataset](https://universe.roboflow.com/classroom-ornbo/exam-cheating-9iz1y-rrfsz-msjrm?utm_source=chatgpt.com)
[ExamCheating MultiV-based Dataset](https://zenodo.org/records/14606173?utm_source=chatgpt.com)

### Video
[ExamCheating MultiV video-based Dataset](https://www.kaggle.com/datasets/rimmajeed/examcheating-multiv-video-based-dataset)


### Purpose

This dataset is used to study and detect student behaviors in examination environments, including:

- Correct Posture
- Left Side Movement
- Right Side Movement
- Forward Movement
- Backward Movement
- Standing
